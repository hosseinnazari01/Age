# Age
# 💻 نمایش سن با زبان C++

این پروژه یک برنامه ساده با زبان برنامه‌نویسی C++ است که یک متغیر عدد صحیح به نام `age` تعریف می‌کند و مقدار ذخیره‌شده در آن را نمایش می‌دهد.

## ⚙️ نحوه عملکرد برنامه

- 📦 تعریف متغیر `age` با نوع داده `int`
- 🔢 مقداردهی متغیر با عدد `20`
- 🖥️ نمایش مقدار متغیر با دستور `cout`
- ✅ پایان اجرای برنامه با `return 0`

## 🧠 مفاهیم استفاده‌شده

- 📚 کتابخانه `iostream`
- 🔤 نوع داده `int`
- 📦 تعریف و مقداردهی متغیر
- 🖨️ دستور `cout`
- 🚀 تابع `main()`

## ▶️ نمونه خروجی
